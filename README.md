# ☕ قهوة شيكو — الموقع + لوحة التحكم

موقع المنيو الإلكتروني لقهوة شيكو، ومعاه **لوحة تحكم** بإيميل وباسورد يقدر منها صاحب المحل:

- يعدّل الأسعار والأسماء
- يضيف ويحذف أصناف وأقسام ويرتّبهم
- يرفع صورة لكل صنف (بتتصغّر تلقائيًا عشان الموقع يفضل سريع)
- يخفي صنف أو قسم مؤقتًا من غير ما يحذفه
- يغيّر اللوجو والعنوان ورقم الواتساب وحسابات الإنستجرام ولينك الخرائط
- يغيّر كلمة السر بتاعته

| الصفحة | الرابط |
|---|---|
| الموقع (المنيو) | `https://your-domain.vercel.app/` |
| لوحة التحكم | `https://your-domain.vercel.app/admin` |

> البيانات كلها (المنيو + الصور) بتتخزن على **Supabase** (خطة مجانية)، والموقع نفسه ملفات ثابتة على **Vercel**.

---

## 📁 الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | صفحة المنيو اللي بيشوفها الزباين — بتقرأ البيانات من Supabase |
| `admin.html` | لوحة التحكم (تسجيل دخول بإيميل وباسورد) |
| `config.js` | **الملف الوحيد اللي بتعدّله**: رابط مشروع Supabase والمفتاح العام |
| `menu-data.js` | المنيو الحالي — بيتستورد منه لقاعدة البيانات أول مرة، وبيظهر كنسخة احتياطية لو Supabase مش متاح |
| `supabase/setup.sql` | سكريبت بيجهّز قاعدة البيانات والصلاحيات ومخزن الصور |
| `vercel.json` | إعدادات Vercel (عشان `/admin` يشتغل من غير `.html`) |

## 🚀 خطوات التشغيل (مرة واحدة — للمطوّر)

> الخطوات ٢ و٣ عايزة الإيميل اللي هيدخل بيه العميل — جهّزه الأول.

### 1) اعمل مشروع على Supabase
1. ادخل على <https://supabase.com/dashboard> وسجّل (مجاني).
2. **New project** → اختار اسم، وكلمة سر لقاعدة البيانات (احفظها)، والمنطقة الأقرب (**Frankfurt / eu-central-1** مناسبة لمصر).
3. استنى دقيقة لحد ما المشروع يجهز.

### 2) شغّل سكريبت قاعدة البيانات
1. افتح ملف `supabase/setup.sql` وغيّر السطر ده لإيميل العميل:
   ```sql
   insert into public.admins (email) values ('client@example.com')
   ```
2. من القائمة الجانبية في Supabase: **SQL Editor** → **New query** → الصق الملف كله → **Run**.
3. المفروض يطلع `Success`. السكريبت بيعمل:
   - الجداول (`categories`, `items`, `settings`, `admins`)
   - صلاحيات القراءة للكل، والكتابة للأدمن بس (Row Level Security)
   - مخزن الصور `menu-images`

> لو شغّلته تاني بالغلط مفيش مشكلة — مش هيمسح أي بيانات.
> المنيو نفسه (الأقسام والأصناف) بيتضاف من لوحة التحكم في الخطوة ٨ بزرار واحد.

### 3) اعمل حساب الدخول للعميل
1. **Authentication** → **Users** → **Add user** → **Create new user**.
2. اكتب **نفس الإيميل** اللي حطيته في السكريبت + كلمة سر قوية.
3. فعّل ✅ **Auto Confirm User** → **Create user**.
4. سلّم الإيميل وكلمة السر للعميل (ويقدر يغيّر كلمة السر من اللوحة بعدين).

### 4) اقفل التسجيل العام (مهم للأمان)
**Authentication** → **Sign In / Providers** → **Email** → اقفل ❌ **Allow new users to sign up** → Save.

> حتى لو حد عمل حساب بطريقة ما، مش هيقدر يعدّل حاجة لأن الكتابة مسموحة بس للإيميلات اللي في جدول `admins`. بس قفل التسجيل بيقفل الباب خالص.

### 5) ظبّط روابط الاستعادة (عشان زرار "نسيت كلمة السر" يشتغل)
**Authentication** → **URL Configuration**:
- **Site URL**: `https://your-domain.vercel.app`
- **Redirect URLs** → Add: `https://your-domain.vercel.app/**`

### 6) اربط الموقع بالمشروع
1. **Project Settings** → **API Keys** → انسخ:
   - **Project URL** (شكله `https://xxxx.supabase.co`)
   - **Publishable key** (بيبدأ بـ `sb_publishable_`) — لو مش موجود اضغط *Create new API keys*. مفتاح `anon` القديم شغال برضه.
2. افتح `config.js` وحطهم:
   ```js
   window.SHIKO_CONFIG = {
     SUPABASE_URL: "https://xxxx.supabase.co",
     SUPABASE_KEY: "sb_publishable_xxxxxxxxxxxx",
   };
   ```
3. ⚠️ **عمرك ما تحط الـ Secret key أو service_role في الموقع** — دول بيتخطوا كل الصلاحيات.

### 7) ارفع على Vercel
ادفع التعديلات على GitHub، وVercel هينشر تلقائيًا. افتح:
- الموقع: `https://your-domain.vercel.app/`
- اللوحة: `https://your-domain.vercel.app/admin` ← سجّل دخول بالإيميل وكلمة السر.

### 8) استورد المنيو الحالي
أول ما تسجّل دخول هتلاقي اللوحة فاضية وفيها زرار **📥 استيراد المنيو الحالي** — اضغطه مرة واحدة وهيضيف الـ ١٠ أقسام والـ ٧١ صنف بأسعارهم وبيانات المحل.

جرّب تعدّل سعر وافتح الموقع — المفروض يتغيّر فورًا. 🎉

## 👨‍🍳 دليل الاستخدام (للعميل)

افتح `/admin` وسجّل دخولك. اللوحة فيها ٤ تبويبات:

| التبويب | تعمل منه إيه |
|---|---|
| 🍽️ **المنيو** | اختار القسم من الشرائط، وهتلاقي كل الأصناف. ✏️ تعديل · 🗑️ حذف · ⬆️⬇️ ترتيب · زرار "ظاهر/مخفي" لإخفاء صنف خلصان مؤقتًا. زرار **＋ إضافة صنف** لإضافة صنف جديد بصورة وسعر (سعر واحد أو أحجام S/M/L). فيه خانة بحث فوق. |
| 📂 **الأقسام** | إضافة/تعديل/حذف/ترتيب الأقسام وأيقوناتها. إخفاء قسم بيخفيه من الموقع من غير ما يمسح أصنافه. **حذف القسم بيحذف كل أصنافه.** |
| 🏪 **بيانات المحل** | اللوجو، اسم المحل، الجملة تحت الاسم، العنوان، رقم الواتساب، الإنستجرام، لينك خرائط جوجل. |
| 🔐 **كلمة السر** | تغيير كلمة السر (٦ حروف على الأقل). |

- أي تغيير بيتحفظ فورًا وبيظهر على الموقع لما الزبون يفتح الصفحة (أو يعمل تحديث).
- الصور بتتصغّر تلقائيًا قبل الرفع، فارفع براحتك من الموبايل.
- لو نسيت كلمة السر: اكتب إيميلك في صفحة الدخول واضغط **نسيت كلمة السر؟** وهيوصلك لينك على الإيميل.

## 🧪 وضع تجريبي (قبل الربط)

لو `config.js` لسه فيه القيم الافتراضية، اللوحة بتشتغل في **وضع تجريبي**:
- الدخول بـ `demo@shiko.com` / `demo1234`
- التعديلات بتتحفظ في متصفحك بس (مفيد لعرض اللوحة على العميل قبل التشغيل)
- أول ما تحط بيانات Supabase في `config.js`، الوضع التجريبي بيتقفل تلقائيًا.

## 🛠️ حل المشاكل

| الرسالة / المشكلة | السبب والحل |
|---|---|
| `الإيميل أو كلمة السر غلط` | تأكد من البيانات، أو اعمل Reset لكلمة السر من Supabase → Authentication → Users |
| `الإيميل ده مش مصرح له بالدخول` | الإيميل مش موجود في جدول `admins`. من **Table Editor** → `admins` → Insert row بالإيميل (بحروف صغيرة) |
| `قاعدة البيانات لسه متجهزتش` / `الجداول مش موجودة` | شغّل `supabase/setup.sql` من SQL Editor |
| `مفيش صلاحية للتعديل` | نفس سبب "مش مصرح له": الإيميل مش في جدول `admins` |
| `الإيميل لسه متأكدش` | من Authentication → Users → افتح المستخدم → Confirm email (أو اعمله تاني مع تفعيل Auto Confirm) |
| الموقع بيعرض المنيو القديم | الموقع بيعرض النسخة الاحتياطية لأن `config.js` غلط أو Supabase مش متاح. افتح Console في المتصفح لتفاصيل الخطأ |
| لينك "نسيت كلمة السر" مش بيفتح اللوحة | ضيف الدومين في Authentication → URL Configuration → Redirect URLs (خطوة ٥) |
| رفع الصور بيفشل | تأكد إن السكريبت اتشغّل (بيعمل الـ bucket)، وإن الصورة JPG/PNG/WebP |

### إضافة أدمن تاني
1. Authentication → Users → Add user (بإيميله + Auto Confirm)
2. Table Editor → `admins` → Insert row بنفس الإيميل

## 🔒 ملاحظات أمان

- المفتاح اللي في `config.js` (Publishable / anon) **عام ومسموح يظهر** — الحماية الحقيقية من صلاحيات قاعدة البيانات (RLS) اللي السكريبت بيظبطها.
- الكتابة (إضافة/تعديل/حذف/رفع صور) مسموحة **فقط** لمستخدم مسجّل دخول وإيميله في جدول `admins`.
- الـ Secret key و service_role ما يتحطوش في أي ملف في الموقع أبدًا.
